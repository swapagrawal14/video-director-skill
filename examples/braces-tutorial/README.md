# Example: Braces — Bonding se Debonding tak (4:40, 21 scenes, Hinglish)

A complete real production made with this skill. Study it for:
- a detailed hero model built from primitives (typodont: gums, both arches, 28 teeth via deformed spheres, brackets, molar tubes, archwire tubes),
- instruments (handpieces, syringes, pliers, curing light, height gauge) and how they travel to the subject,
- per-scene FX inside `renderAt` (etch gel, rinse particles, cure glow, time-lapse alignment, debonding),
- 3D-anchored labels on moving parts, step chips, badges, list cards.

This file predates `project.json`: its timing (`VO`, `EXTRA` arrays) and subtitles (`SUB`) are inline. To re-render it, put its VO files in `vo/` and use it as `index.html` in a project folder with `fonts/` and `node_modules/`.
`script.json` holds the 21 Devanagari-Hinglish VO lines given to TTS.
